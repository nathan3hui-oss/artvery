漢摩拉比法典

古巴比倫 · 公元前1792—前1750年

Code de Hammurabi

導賞節錄

石碑最頂刻住兩個人：左邊企住嘅係巴比倫國王漢摩拉比，右邊坐住嘅係沙瑪什，佢既係太陽神，亦係保護公正嘅神。留意神嘅膊頭冒緊火焰，腳下踩住一級級象徵山峰嘅台，呢啲就係認出佢嘅標誌。佢正向國王展示一個環同一支杖，代表權力。

呢塊石碑高兩米二五，係玄武岩，一般叫做《漢摩拉比法典碑》。佢同公元前十八世紀嘅巴比倫王漢摩拉比有關，碑文大約喺公元前一千七百五十年刻嘅。碑文開頭將漢摩拉比形容成受眾神委派、維護公正、唔畀強者欺負弱者嘅統治者。不過，「國王嘅法律紀念碑」唔等於國王親手刻嘅石。

— 廣東話講稿 · Artvery
