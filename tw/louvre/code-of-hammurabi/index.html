漢摩拉比法典

古巴比倫 · 西元前1792—前1750年

Code de Hammurabi

解說節錄

石碑頂端的兩個人是誰？左邊站著的是巴比倫國王漢摩拉比，右邊坐著的是沙瑪什，他既是太陽神，也是公正的保護神。注意神的肩膀上冒著火焰，腳下踩著一級級象徵山峰的臺子，這是辨認他的標誌。他正向國王展示一個環和一根杖，這是權力的象徵。

這塊石碑高兩公尺二五，是玄武岩，常被稱作《漢摩拉比法典》。它和西元前十八世紀的巴比倫王漢摩拉比有關，碑文大約刻於西元前一千七百五十年。碑文的開頭把漢摩拉比描寫成受諸神委任、維護公正、不讓強者欺壓弱者的統治者。不過，「國王的法律紀念碑」不等於國王親手刻的石頭。

— 國語講稿 · Artvery
