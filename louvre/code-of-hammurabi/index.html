汉谟拉比法典

古巴比伦 · 公元前1792—前1750年

Code de Hammurabi

讲解节选

石碑顶端的两个人是谁？左边站着的是巴比伦国王汉谟拉比，右边坐着的是沙马什，他既是太阳神，也是公正的保护神。注意神的肩膀上冒着火焰，脚下踩着一级级象征山峰的台子，这是辨认他的标志。他正向国王展示一个环和一根杖，这是权力的象征。

这块石碑高两米二五，是玄武岩，常被称作《汉谟拉比法典》。它和公元前十八世纪的巴比伦王汉谟拉比有关，碑文大约刻于公元前一千七百五十年。碑文的开头把汉谟拉比描写成受诸神委任、维护公正、不让强者欺压弱者的统治者。不过，"国王的法律纪念碑"不等于国王亲手刻的石头。

— 普通话讲稿 · Artvery
